# Architecture Decision Records

This directory records significant architectural decisions for the MLOps platform.
Each ADR is immutable once accepted; a decision is changed by adding a new ADR that
supersedes an old one (never by editing history).

Format follows the assignment's ADR template: Status, Context, Decision,
Alternatives Considered, Consequences, Follow-up Actions.
